# Portfolio PHP - DRAME ALGORIX

Portfolio personnel développé avec PHP, HTML, CSS et JavaScript.

## Description

Ce projet est une version dynamique de mon portfolio.  
Il utilise PHP pour organiser le site avec des composants réutilisables comme la navigation, le footer et les fonctions de validation.

## Fonctionnalités

- Pages dynamiques en PHP
- Composants réutilisables avec `require`
- Navigation active selon la page courante
- Formulaire de contact avec validation PHP
- Formulaire de demande de projet avec récapitulatif
- Recherche dynamique des projets avec `$_GET`
- Affichage dynamique des projets depuis un tableau PHP
- Design responsive avec HTML, CSS et JavaScript

## Déploiement

Ce projet est déployé sur InfinityFree, car GitHub Pages ne prend pas en charge PHP.

GitHub est utilisé uniquement pour stocker le code source.

## Technologies utilisées

- PHP
- HTML5
- CSS3
- JavaScript
- InfinityFree
- GitHub
